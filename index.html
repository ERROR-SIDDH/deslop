Claude Code skill

deslop

Turn AI-generated websites into design that holds up next to Stripe, Linear and IBM. deslop audits a page, picks one design direction and ports colour, type, components, radius, motion and copy to an enterprise standard.

InstallAdd the skill to Claude Code in one copy command. See the demosThree before-and-after ports, with measurements.

Install

You need Claude Code and Node.js 18 or later for the helper scripts. Copy the deslop folder into your skills directory.

macOS and Linux

bash
git clone https://github.com/ERROR-SIDDH/deslop.git
mkdir -p ~/.claude/skills
cp -r deslop/deslop ~/.claude/skills/deslop

Windows

PowerShell
git clone https://github.com/ERROR-SIDDH/deslop.git
New-Item -ItemType Directory -Force "$HOME\.claude\skills" | Out-Null
Copy-Item -Recurse deslop\deslop "$HOME\.claude\skills\deslop"

For one project only

Copy the folder to .claude/skills/deslop inside that repository and commit it. Everyone on the team gets the skill.

Skills load when a session starts. Open a new Claude Code session, then type /deslop to confirm it is there. To update, git pull and copy the folder again.

Usage

Open Claude Code in the project you want to fix. Run /deslop, or describe the problem. The skill also triggers on phrases like “this looks AI-generated”, “too purple” or “make it look enterprise”.

Prompt
/deslop our landing page in src/app/page.tsx.
Brand colour is #6366F1 and must stay. We sell to enterprise IT teams.

What to tell it

deslop never invents customers, numbers or claims. The more facts you give it, the sharper the result.

Give itSo that it can
Your brand colour, and whether it must stayKeep the hue and discipline it, instead of replacing it
How the product is boughtChoose the house style: Enterprise, Product-mono or Editorial
Which stats and testimonials are realKeep those, and remove or flag the rest
Marketing page or app screenUse the right type scale and component patterns
A URL or dev-server portRun the live audit and compare screenshots

The core finding

Blue and purple are not the problem. The treatment is. We measured live AI-built landing pages against Linear and Stripe with the bundled audit script.

Stripe is 97% indigo and still reads as premium: no gradient text, 4–6px corners, one licensed typeface, no icon confetti. So deslop removes the tells and imposes a system rather than swapping colours.

The classic AI button colours fail accessibility. With white text, Tailwind violet-500 scores 4.23:1, indigo-500 4.47:1 and blue-500 3.68:1, all under the 4.5:1 minimum.

How it works

  1. AuditThe static scanner runs over the source, and the live audit runs on the rendered page. You get a ranked list of the loudest tells.
  2. DecideIt picks one house style from how the product is bought, and decides what happens to the brand colour.
  3. PortIt works source first: generated tokens, then type, then removing the tells. Then come colour placement, component choice and sizing, the stock sections, and copy.
  4. VerifyIt re-scans, re-audits and re-screenshots, then runs a 13-point review gate before reporting what changed and what it flagged.

Rules it enforces

  • Colour budget. 90–96% neutral. Accent only on the primary button, links, focus ring, selected states and one chart series.
  • One primary button per view, three text levels, at most three surface levels.
  • Least decorated object. Rows before cards, tables for records, an inline stat row instead of stat cards.
  • One radius scale with four steps. 1px borders. Controls at 32, 36–40 or 44px.
  • Nothing moves on its own. No glows, glass, blobs or hover lifts.

Static scanner

slop-scan.mjs reports every tell as file:line with a fix. It covers 29 patterns, including project-wide checks for mixed grey families, multiple accent hues and radius sprawl. It has no dependencies and ignores comments.

bash
node deslop/scripts/slop-scan.mjs src/
node deslop/scripts/slop-scan.mjs src/ --json
node deslop/scripts/slop-scan.mjs --self-test
Output
[!!!] gradient-text x2  ->  Solid foreground headline; never gradient text.
   src/app/page.tsx:16  bg-clip-text text-transparent
[!!] multiple-accent-hues x1  ->  One accent hue; everything else neutral.
   purple + cyan + blue + indigo + pink
111 tells, weighted 223. Full AI-slop: run the deslop port.

Palette generator

derive-palette.mjs takes one brand colour and a house style, and returns a complete light and dark token set computed in OKLCH. It keeps the hue, caps the chroma so the colour stops looking neon, and deepens the lightness until white text passes 4.5:1. Dark mode is designed separately, not inverted.

bash
node deslop/scripts/derive-palette.mjs "#8B5CF6" C
node deslop/scripts/derive-palette.mjs none B --format=oklch
node deslop/scripts/derive-palette.mjs "#2563EB" A --format=hsl

It outputs shadcn-compatible variables, plus the tokens the rules need: hover and active states, a subtle selected state, readable status text, chart series and a four-step radius scale. A 28-line contrast report ends the output.

Output
--primary: #5c39a9;   /* from #8B5CF6, which fails AA with white text */
/* ok   light primary-foreground on primary: 8.04 (min 4.5) */
/* ok   dark  muted (hover) visible on card: 1.13 (min 1.05) */

How it was tested

  • Field study. Live Lovable and v0 pages were measured in a real browser, with Linear and Stripe as calibration.
  • Reference research. Design tokens and rules from IBM Carbon, GitHub Primer, Vercel Geist, Linear, Atlassian and Stripe.
  • Blind ports. Four fresh agents, each given only the skill and an AI-made page. Over 30 ambiguities they reported were fixed between runs.
  • Self-tests. Both Node scripts ship with --self-test. The generator checks every contrast pair for eight brand colours across all three styles.

Limits

  • The scores are heuristics, calibrated on five AI sites and two premium sites. The review gate is the real bar.
  • The scanner reads Tailwind, CSS, HTML and JSX. It cannot judge hierarchy or whether a claim is true.
  • Screenshots and the live audit need a browser. Without one, the skill relies on the scan and the review gate.
  • The demo products are fictional.
